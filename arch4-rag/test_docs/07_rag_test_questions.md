# RAG 평가용 질문

아래 질문은 이 문서 모음에 대한 RAG 시스템의 검색 및 답변 품질을 평가하기 위한 것이다.

## 단일 문서 검색 질문
1. Kinesis Data Streams의 역할은 무엇인가?
2. OpenSearch는 이 아키텍처에서 어떤 목적으로 사용되는가?
3. S3 Raw Data의 예시 경로는 무엇인가?
4. Athena는 데이터를 어디에 저장하는가?
5. Glue Database와 Glue Table의 차이는 무엇인가?

## 비교 질문
6. OpenSearch와 S3의 용도 차이를 설명하라.
7. Kinesis Data Streams와 Kinesis Data Firehose의 역할 차이는 무엇인가?
8. Glue Table과 Athena의 역할을 비교하라.

## 멀티홉 질문
9. 데이터 생산자가 이벤트를 생성한 뒤 Athena에서 SQL로 조회하기까지의 전체 흐름을 설명하라.
10. 하나의 이벤트가 실시간 검색과 장기 분석에 각각 어떻게 전달되는지 설명하라.
11. 지난 1년간 데이터를 SQL로 분석하려면 어떤 서비스들이 연결되는가?
12. 실시간 대시보드와 장기 데이터 분석에 서로 다른 경로가 필요한 이유는 무엇인가?

## 함정 질문
13. Athena가 S3에 데이터를 저장하는 서비스인가?
14. Glue Database가 실제 이벤트 데이터를 저장하는 데이터베이스 서버인가?
15. OpenSearch가 Raw Data의 장기 보관을 위한 기본 저장소인가?
16. Kinesis Data Streams가 S3에 직접 SQL 쿼리를 수행하는가?

## 조건부 질문
17. 최근 5분 이벤트를 빠르게 검색하려면 어떤 경로를 선택하는 것이 적절한가?
18. 1년치 Raw Data에 대해 SQL 집계를 수행하려면 어떤 경로를 선택해야 하는가?
19. 원천 데이터를 재처리할 가능성이 있다면 어느 저장소에 보관하는 것이 적절한가?
20. S3의 새로운 이벤트 데이터셋을 Athena에서 조회하려면 어떤 메타데이터 구성이 필요한가?
